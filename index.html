Getting Started

Option 1 | Prebuilt executable

Browse the published build files in the repository.

Open the dist folder ->

  • SafeUSB-Eject.exe
  • Safe-USB-Eject.ps1
Important: Keep the companion PowerShell script in the expected location relative to the executable. The EXE should not be assumed to be standalone.

Option 2 | Build from source

Requirements: Windows, Rust/Cargo, and PowerShell.

git clone https://github.com/tcdoverlord/Windows-USB-Safe-Eject.git
cd Windows-USB-Safe-Eject

See BUILD-EXE.bat and the project documentation for build instructions.

Safety Safety Notes

  • Close files and applications that may be using the USB drive.
  • Do not disconnect the drive if Windows reports that it is still in use.
  • If ejecting fails, follow the app's status message and resolve the issue before retrying.
  • A completion indicator is not proof of physical removal or data integrity.

Read the project safety documentation before use.
